使用本地数据

录像和检测文件只在当前浏览器中读取。检测流从第 1 帧连续编号，可用 xyxy 或带逐帧宽高的 YOLO 中心框格式；两者不能混用。

处理流程

检测器负责产生观测，MBMOT 负责身份关联和空间状态。

  1. 输入Detection边界框、分数、类别
  2. 关联Tracker稳定 track_id
  3. 规则SpatialAnalyzer线和区域状态
  4. 输出Events计数、占用、停留

接入方式

直接调用 MoonBit API，也可以通过文本协议与现有推理程序连接。

moon add python123-ops/mbmot@0.2.0

let tracker = @mbmot.Tracker::new(
  @mbmot.TrackerConfig::default(),
)
let frame = tracker.update(frame_id, detections)
{"frame":1,"detections":[
  {"xyxy":[120,80,260,410],
   "score":0.91,"class_id":0}
]}
moon run --target native --release src/mot_track \
  detections.txt tracks.txt

输入边界

  • 单摄像头、轴对齐检测框
  • 网页录像检测流从第 1 帧连续编号
  • 规则与轨迹使用同一坐标尺度
  • 不执行图像推理、ReID 或多摄像头身份合并
